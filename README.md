# KalaOS

**KalaOS is my authored portfolio operating system:** a visual profile experience that introduces who I am, what I build, and the work I care about.

I’m Kalaab Alebachew, a software engineering student and full-stack developer in Addis Ababa. I build mobile and web products, with a focus on practical tools, clear interfaces, and maintainable systems.

## What I build

- Cross-platform apps with **Flutter and Dart**
- Web interfaces with **React**
- APIs and backend services with **Node.js** and **Python/FastAPI**
- Data-backed products using **MongoDB**

## Selected projects

- [GitHub Repository Inspector](https://github.com/kalaabalb/github-repo-inspector) — turns public repositories into bounded, evidence-backed technical reports.
- [Family Academy Client](https://github.com/kalaabalb/family-academy-client) — Flutter learning app for courses, study materials, exams, and student progress.
- [Family Academy Admin](https://github.com/kalaabalb/family-academy-admin) — React dashboard for managing educational content and platform operations.
- [Family Academy Landing Page](https://github.com/kalaabalb/familyacademy.et) — public landing page and download hub.
- [KalaOS Portfolio](https://kalaabalb.github.io) — the live portfolio experience.
