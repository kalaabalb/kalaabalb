# KalaOS Origin Mark Specification

The Origin Mark is the first visual principle of KalaOS.

It is not a logo.
It is not branding.
It is not decorative artwork.

It is a construction symbol that represents one idea: everything begins from an origin.

The mark must feel unfinished. It represents possibility rather than completion.

## 1. Concept

The mark communicates the start of a system.

It does not describe identity.
It does not advertise a product.
It does not act like an emblem.

It marks the point from which construction expands outward.

## 2. Geometry

The mark is composed of exactly five structural elements:

1. One precise central point.
2. One vertical construction segment above the origin.
3. One vertical construction segment below the origin.
4. One horizontal construction segment to the left.
5. One horizontal construction segment to the right.

The central point is the only enclosed element.

The four line segments do not touch the origin.
A small intentional gap separates every segment from the center.

The four segments do not meet each other.
The negative space between them is part of the design.

The mark must never resemble:

- a cross
- a target
- a plus sign
- a medical symbol
- a compass
- a cursor

It should feel measured rather than symbolic.

## 3. Proportions

The base unit is the diameter of the central point.

All other dimensions derive from that base unit.

Recommended proportional system:

- central point diameter: `1u`
- gap between point and each segment: `0.75u`
- segment stroke width: `0.5u`
- segment length: `2.5u`
- outer margin for the whole form: `2u`

The construction should remain mathematically consistent at every size.
No dimension should be arbitrary.

## 4. Clear Space

The mark requires a protected clear space around it.

That clear space must scale proportionally with the base unit.

Recommended minimum clear space: `2u` on every side.

No text, icon, border, particle, or decorative element may intrude into that region.

## 5. Sizes

### 12 px

At 12 px, the mark must reduce to its essential logic.

The point must remain visible.
The four segments must still read as separate construction cues.
No decorative detail may survive if it harms legibility.

### 16 px

At 16 px, the mark should feel clearly structured.

The gap between the center and the segments must remain visible.
The form should still feel unfinished, not symbolic.

### 24 px

At 24 px, the construction logic should become obvious.

The visitor should be able to see the four-part expansion around the center.

### 48 px

At 48 px, the symbol should feel precise and architectural.

The spacing between elements becomes part of the identity.

### 128 px

At 128 px, the mark should reveal its calibration discipline.

The viewer should notice the balance between the center and the four segments.

### 512 px

At 512 px, the mark should still feel restrained.

It should not become ornamental.
Its strength should come from proportion and restraint, not complexity.

## 6. Animation

The mark assembles.

It never pops into existence.

Assembly order:

1. Origin point.
2. Upper segment.
3. Lower segment.
4. Left segment.
5. Right segment.

The timing should feel deliberate.
Never dramatic.
Never playful.
Never elastic.

Disassembly must follow the reverse order.

The mark must not animate continuously.
It may appear during boot, calibration, or reveal sequences only.

## 7. Usage

Allowed usage:

- boot sequence
- corner references
- blueprint overlays
- loading states
- watermarks
- documentation
- window construction
- calibration indicators
- hidden easter eggs
- small recurring identity marks

## 8. Prohibited Usage

The Origin Mark must never:

- rotate
- distort
- stretch
- skew
- outline
- add gradients
- add shadows
- sit inside circles
- sit inside squares
- contain text
- animate continuously
- pulse
- glow
- become decorative

## 9. Semantics

The Origin Mark communicates:

- origin
- construction
- reference
- precision
- potential

It should feel like the first measurable event in a system that is still assembling itself.
